# my-portfolio

Personal portfolio site built with Next.js, TypeScript and Tailwind CSS.

## Edit your content

Everything you'd want to change lives in **`src/data/portfolio.ts`**:
name, headline, bio, experience, projects, skills and links.

- Résumé: drop your PDF at `public/resume.pdf`
- Colors: change `--accent` and `--accent-2` in `src/app/globals.css`

## Run locally

```bash
npm run dev
```

Open http://localhost:3000.

## Deploy

Push this repo to GitHub, then import it at https://vercel.com/new — it
detects Next.js automatically and deploys for free.
